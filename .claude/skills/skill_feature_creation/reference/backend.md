# Backend (api/graphlagoon)

Read the sibling named in SKILL.md step 2 for the code shape; this file is
only the map and the traps.

## Where things go

| Piece | Location | Note |
|---|---|---|
| Pydantic schemas | `models/schemas.py` (2.8k lines) | grep for a sibling model and read that range; check `extra="forbid"` before sending new fields from the frontend |
| SQLAlchemy models | `db/models.py` | SQLAlchemy 2.0 `Mapped[...]` style |
| In-memory twin | `db/memory_store.py` | a `Memory<Entity>` dataclass, a dict on `InMemoryStore`, and a line in `clear_all` |
| Migration | `alembic/versions/NNN_<name>.py` | next number after the highest; see below |
| Business logic | `services/<area>.py` | routers stay thin |
| Routes | `routers/<area>.py` | register in `create_api_router()` in `app.py` |
| Settings / env vars | `config.py` `Settings` | prefix `GRAPH_LAGOON_`; classify in `CONFIG_FIELD_KINDS` (gate 4.2b) and document in `docs/guide/configuration.md` |

## Two persistence modes

Every stored entity works with and without Postgres. Routers branch on
`is_database_available()`:

```python
if is_database_available():
    async with get_session_maker()() as session:
        await check_context_access_db(session, context_id, user_email)
        ...
else:
    check_context_access_memory(context_id, user_email)
    store = get_memory_store()
    ...
```

Tests run on the memory path by default, so a missing DB branch passes the
suite and fails in production. Implement and review both.

## Migrations

```bash
make migrate-create   # prompts for a name; autogenerates against a running DB (make db-up)
make migrate          # upgrade head
```

Existing migrations are hand-numbered (`016_cases.py`, `revision = "016"`,
`down_revision = "015"`) and idempotent: they inspect existing tables and
columns before creating. Keep both conventions; rename an autogenerated file
to the next number. Add an index for any new column you filter or join on.

## Auth and access

- Who is calling: `user_email = get_current_user(request)`
  (`middleware/auth.py`), or `Depends(require_permission("<id>"))` when the
  route is a gated action (gate 2.4b).
- Access to a context: `utils/context_access.get_context_with_access`, or
  the `check_context_access_db` / `_memory` pair. Role checks:
  `utils/authz.can_write`, `can_manage`, `is_superuser`.
- Ownership and share checks stay as separate AND-gates next to a
  permission gate; one does not replace the other.

## Errors

Routers return structured details so the frontend can branch on a code:

```python
raise HTTPException(status_code=404,
    detail={"error": {"code": "STYLE_PRESETS_DISABLED", "message": "...", "details": {}}})
```

Copy the `_error(status, code, message, details)` helper from a sibling
router. Translate service exceptions to 4xx in the router; never let a
warehouse or SQL error leak as a bare 500 with the query text.

## Mutating routes

A new `POST`/`PUT`/`DELETE` must be audited or explicitly exempt, or
`tests/test_admin_registry.py` fails:

```python
await audit.record(user_email, AuditAction.<ACTION>, resource_type="...", resource_id=...)
```

plus the `(method, path)` in `AUDITED_ROUTES` — or in `AUDIT_EXEMPT_ROUTES`
with a reason. Full table: `gates.md`.

Routes under `/api/investigations` or `/api/org`, and MCP tools, also need a
docstring, one `tags=[...]` group, an MCP mirror or exemption in
`mcp/registry.py`, and `make docs-api` to regenerate
`docs/guide/agents-mcp-tools.md` and `docs/public/openapi.json`.
`make docs-api` is also what fixes a red `test_api_docs` after any route,
schema or version change.

## Checks

```bash
cd api && uv run pytest tests/test_<area>.py -q -p no:cacheprovider
cd api && uv run ruff check <files you changed>
```

The tree is not ruff-clean as a whole (older lint findings and unformatted
files), so check the files you touched and do not reformat unrelated code
in a feature diff.

Setup: `cd api && uv sync --extra dev --extra postgres` (the suite imports
Alembic migrations; without the `postgres` extra some tests error out).

New dependency: add it to `api/pyproject.toml`; prefer the standard library
or something already installed.
